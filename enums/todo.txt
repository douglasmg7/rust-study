?
When you append ? to a Result value, Rust performs two actions depending on the variant:
• On Ok(val). It unwraps val and assigns it to your variable or passes it to the next expression, allowing the function to continue running.
• On Err(e). It immediately exits the current function and returns Err(e) to the calling code. It also automatically converts the error type using the From trait if the function's return error type differs from the expression's error type.
